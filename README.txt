MY LOAN LEDGER - FREE OFFLINE iPHONE WEB APP

FILES: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png

HOW TO INSTALL:
1. Extract the ZIP on a computer.
2. Create a free GitHub account and a public repository (note: the source code is public, but loan records are stored only on your phone).
3. Upload all five files to the repository root.
4. Under Settings > Pages, choose Deploy from a branch, main, /(root), then Save.
5. Wait for GitHub to display your HTTPS website URL.
6. Open that URL in Safari on your iPhone while online.
7. Tap Share > Add to Home Screen > Add.
8. Launch the home-screen app, add a test loan, and verify it works in Airplane Mode.

DATA SAFETY:
- Loan records are stored locally in this iPhone's web app storage, NOT on GitHub.
- Export a JSON backup after changes and save it in a secure place.
- Restore replaces all existing records.
- Backups are not encrypted; protect the backup file.
- Clearing website data, changing phones or reinstalling can lose records.
- No login, PIN, automatic cloud sync, or automatic reminders.
- Monthly interest is an estimate, not an accrued/overdue interest ledger.
